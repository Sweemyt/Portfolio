# vibeCoding Portfolio

Personal portfolio website presenting my profile, skills, projects, certifications, and technology watch. The site is written in French and built with HTML, CSS, and JavaScript.

## Contents

- `index.html` — the portfolio page and its sections
- `styles.css` — layout, styling, and responsive presentation
- `script.js` — page interactions
- `images/` — backgrounds, skill icons, project images, and technology-watch images
- `fichiers/` — CV, certifications, and internship reports
- `contactForm.php` — PHP contact-form handler

## Run locally

Open `index.html` in a browser to view the static page. To run it through PHP locally, start PHP's built-in development server from this directory:

```sh
php -S localhost:8000
