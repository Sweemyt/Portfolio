# Portfolio Bootstrap

Personal portfolio website presenting my profile, education, skills, technology watch, and contact information. The site is written in French and uses HTML, CSS, JavaScript, Bootstrap 4, and a PHP contact-form handler.

## Contents

- `index.html` — the portfolio page and its sections
- `stylesheet.css` and `stylesheet2.css` — custom styling
- `script.js` — page interactions
- `contactForm.php` — contact-form handler using PHP's `mail()` function
- `images/` — portfolio and technology images
- `fichiers/` — CV document

## Run locally

Open `index.html` in a browser to view the page. To submit the contact form, use a PHP-enabled server. For a local preview, start PHP's built-in development server from this directory:

```sh
php -S localhost:8000
